# BigChatBox v7.0.1 - I intend to live forever

## All versions

### Change
- Protected commands such as /cast, /target and /focus now move to Blizzard's chat box instead of failing: press Enter again to run them.

### Fixed
- /join and /leave typed in BigChatBox no longer give an "action blocked" error on Retail and WoW Forever: they move to Blizzard's chat box, press Enter again to run them.
- Accepting the "allow scripts" popup after a /run, /script or /dump from BigChatBox no longer fails: until scripts are allowed, these commands move to Blizzard's chat box.
- A chat lockdown without combat now says "Paused during a chat lockdown" instead of "combat", and is announced again the next time it starts.
- A command typed while a lockdown began is no longer posted to chat as plain text.

## Classic only

### Fixed
- The language choice in the setup wizard and Settings > Advanced is now shown on Classic too.
