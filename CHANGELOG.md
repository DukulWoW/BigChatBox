# BigChatBox v7.1.0 - I intend to live forever

## All versions

### New
- Channel history on the box. Switch it on in Features: a panel above (or below) the box shows the recent messages of the channel you are typing in, with times, clickable links and a scroll bar, or all chat with one click. BigChatBox keeps up to 200 messages per channel for the session, more than the chat tabs hold. Choose whether it opens with the box or waits for its button.

### Fixed
- Clicking a channel name in chat (Trade, Guild, Party, ...) opens the box on that channel again, instead of the one you last posted in. Works with Chattynator too.
